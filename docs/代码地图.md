## 模块

- `assets/scenes/Main.scene`：唯一场景，仅含 `Canvas`（1624 × 750）、`Camera` 和挂载在 `Canvas` 上的 `Boot`。
- `assets/scripts/Boot.ts`：场景唯一入口，初始化 `Stage3DRig`、`Machine`、`TankRoot`、`ShellView`、`Hud`、`LevelLoader`、`PillarEnergyController` 与 `LevelState`，由 `LevelLoader` 默认载入 `X01`（或 `?level=...`）并驱动 `loadLevelSession` / `restartCurrentLevel`。
- `assets/scripts/config/LayoutConfig.ts`：1624 × 750 整机各分区矩形常量（扩容内屏 `1060 × 606`）、`rectCenter` 与 `calcMachineScale`（纯 TS）。
- `assets/scripts/config/TankSpace.ts`：缸坐标工具（原点在内屏左下角，提供 `0~100` 百分比、像素与机器坐标互转，纯 TS）。
- `assets/scripts/config/GameConst.ts`：全局调试开关 `DEBUG` 与纤巧 3D 正圆环、精巧三段式锥形十字柱（`0.88x` 短卡托）、`122px` 圆弧底角、锁定/消除下落及充能技能常数（纯 TS）。
- `assets/scripts/config/FeelConfig.ts`：12 个体感参数配置 `FeelParams` / `DEFAULT_FEEL_CONFIG`（柱位 `32.5%`、尾尖离底 `31%`、海眼 `14%`）及底层基数 `FEEL_BASE_CONST`（纯 TS）。
- `assets/scripts/config/PhysicsGroups.ts`：逻辑碰撞分组位掩码与规则校验（纯 TS）。
- `assets/scripts/config/Palette.ts`：灰盒与 3D 圈柱配色表（机身、深水内屏、青碧玉柱、七种锁脉环与调参面板颜色）。
- `assets/scripts/core/physics3d/Math3D.ts`：纯 TS 三维向量、四元数积分、3x3 逆惯量张量及圆环/线段最近点几何函数。
- `assets/scripts/core/physics3d/TorusBody3D.ts`：真 3D 标准正圆环刚体（精确圆环惯量、三维施力/力矩与空间点速度查询，纯 TS）。
- `assets/scripts/core/physics3d/PillarCollider3D.ts`：三段式「上尖下粗细锥杆 + 收短防卡十字卡托（碰撞翼展短于视觉翼展）+ 悬空尾椎」光滑胶囊碰撞几何（纯 TS）。
- `assets/scripts/core/physics3d/TorusContactDetect.ts`：圆环对六面水缸墙/圆弧底角、锥形十字柱及圆环对圆环的多接触点检测（纯 TS）。
- `assets/scripts/core/physics3d/TorusWorld3D.ts`：薄层 3D 水缸顺序冲量刚体物理世界（120Hz 双子步、库仑摩擦与无能量位置防穿模，纯 TS）。
- `assets/scripts/core/rings/RingKinds.ts`：圈种（普通 4 色、小金环、铁圈、木圈）尺寸/下沉/跟随倍率及 `sameKind` 配对规则（纯 TS）。
- `assets/scripts/core/rules/PillarStack.ts`：柱子槽位管理 `PillarStack`、三维套中判定 `isRingOnPillar3D` 及保留自然微倾锁定 `clampLockedRingPose3D`（纯 TS）。
- `assets/scripts/core/rules/MatchRule.ts`：同款消除配对检查、剩余各圈新槽位高度重算及平滑下落插值函数（纯 TS）。
- `assets/scripts/core/rules/FunnelMath.ts`：入柱宽容三维碗口判定、居中力与就近回正力矩及增益合并纯函数（纯 TS）。
- `assets/scripts/core/rules/Energy.ts`：柱子充能纯逻辑 `PillarEnergy`（套中 `+10%`、消除额外 `+40%`、满 `100%` 触发与溢出保留、技能期暂停及关卡开关，纯 TS）。
- `assets/scripts/core/flow/CurlNoise.ts`：用 `SeededRandom` 初始化排列表的旋度噪声，纯函数不消耗随机序列（纯 TS）。
- `assets/scripts/core/flow/JetProfile.ts`：海眼锥形喷流几何构造与单口采样纯函数，供 `FlowField` 与 `FeelSolver` 共用（纯 TS）。
- `assets/scripts/core/flow/FeelSolver.ts`：1D 竖直小模拟反推求解器，将 12 个体感参数换算为 `SolvedFeelConfig` 并提供 `applyFeel()`（纯 TS）。
- `assets/scripts/core/flow/FlowField.ts`：水流速度场（提供 2D `velocityAt` 与含纵深涡流/回中的 3D `velocityAt3D` 及 `addTerm`/`removeTerm`，纯 TS）。
- `assets/scripts/core/flow/WaterFollow.ts`：水流跟随加速度纯函数 `calcEndpointFollowAccel`（纯 TS）。
- `assets/scripts/core/input/Bladder.ts`：软胶气囊模型 `Bladder` 与键帽下陷姿态计算 `calcSoftCapPose`（纯 TS）。
- `assets/scripts/core/level/LevelData.ts`：关卡数据结构定义、配对等价类键、充能开关解析与安全的 URL `?level=` 解析（纯 TS）。
- `assets/scripts/core/level/validateLevel.ts`：校验关卡圈数（≤12）、同时出现圈种（≤5）、百分比坐标范围、时间/种子及机关角色表（纯 TS）。
- `assets/scripts/core/level/LevelRingLayout.ts`：基于 `SeededRandom(seed)` 避开缸壁圆弧、`PillarCollider3D` 与他圈的确定性初始坐标和 3D 姿态生成器（纯 TS）。
- `assets/scripts/core/level/LevelState.ts`：关卡五状态机（`ready`/`playing`/`paused`/`won`/`lost`）、物理时间倒计时、`addTime` 与 `formatCountdown`（纯 TS）。
- `assets/scripts/core/util/SeededRandom.ts`：mulberry32 种子随机数生成器（纯 TS）。
- `assets/scripts/game/LevelLoader.ts`：从 `resources/levels/` 加载与校验关卡 JSON、按 `seed` 确定性摆圈，支持 `?level=X02` 且兼容无 DOM 小游戏环境。
- `assets/resources/levels/X01.json` – `X03.json`：三个灰盒试验关（6、9、12 圈，3–5 种圈）。
- `assets/scripts/game/PhysicsStepper.ts`：固定 `1/60s` 步长推进 `TorusWorld3D`，提供步前/步后回调、`running` 暂停开关与累计物理时间 `elapsed`。
- `assets/scripts/game/TankGeometry.ts`：计算四面缸壁与左右底角圆弧折线的纯几何函数（纯 TS）。
- `assets/scripts/game/Tank.ts`：同步 `TorusWorld3D` 水缸尺寸并用单个 `Graphics` 在背景层绘出深水底色、圆弧底角与海眼标记。
- `assets/scripts/game/Pillar.ts`：创建左右对称三段式锥形十字柱（注册 `PillarCollider3D`，在 `Tank3DRoot` 下挂载 3D 回转体、十字翼、10 格能量刻度与柱尖呼吸灵珠）。
- `assets/scripts/game/PillarEnergyController.ts`：订阅 `ScoreJudge.onRingLocked` 与 `PhysicsStepper`，驱动 `PillarEnergy`、双柱 3D 刻度/灵珠与技能触发事件（供 T018/T019 订阅）。
- `assets/scripts/game/Ring.ts`：真 3D 正圆环组件（持有 `TorusBody3D` 与 `Torus` 3D 网格节点并同步三维位置与四元数）。
- `assets/scripts/game/RingLayer.ts`：3D 圈管理层，步前施净下沉力并在 `lateUpdate` 同步全部 3D 环姿态。
- `assets/scripts/game/WaterForce.ts`：步前推进气囊与 `FlowField`，对每个正圆环圆周 4 个正交方位点施三维水力与盘面迎水翻转力矩。
- `assets/scripts/game/ScoreJudge.ts`：步后检查三维入柱条件，连续稳定 0.3 秒后原地静默休眠；锁定后触发 `MatchRule` 同款消除（闪烁销毁并移除刚体、上方圈保微倾沿 Y 平滑下落），对外发出 `onRingLocked` 与 `onMatchCleared`。

- `assets/scripts/debug/PhysicsDebugDraw.ts`：受 `DEBUG` 控制，按 `P` 键用单 `Graphics` 显示/隐藏水缸、锥形十字柱胶囊骨架与 3D 圆环碰撞圈。

## 约定与坑

- 施力必须在 `PhysicsStepper.onBeforeStep` 固定步内执行，判定在 `onAfterStep` 执行；暂停时置 `PhysicsStepper.running = false`。
- 每个 `Graphics` 组件约占 2MB 显存，同类 2D 图形共用一个。
- 浏览器标签页在后台时帧率会被压低，测手感和帧率时窗口要在前台；按键盘快捷键前先点一下画布聚焦。
- Cocos 3.8.8 规定**每个 `.ts` 脚本最多只能有一个 `Component` 子类**（`@ccclass`）。
- Cocos 3.8.8 由 `empty-2d` 模板创建的项目不会把 `builtin-standard` 打包进内置资源（仅含 `builtin-unlit`），3D 网格使用自定义 `resources/effects/matcap.effect`，且异步加载完成后必须创建新 `Material` 实例重新赋给 `mr.material` 才能刷新 `MeshRenderer` 的 PSO。
- Cocos 3.8.8 预览器默认受内置 `runtime-bridge` 接管引擎模块列表，玩法物理直接走 `core/physics3d/TorusWorld3D` 纯 TS 求解器最轻量稳定，还能省去约 365KB 的物理引擎包体。
- 多台 2D 相机渲染同一 `Canvas` 时，若节点共用 `Layers.Enum.UI_2D` 会被两台相机重复绘制；2D 背景层与前景外壳层必须用独立自定义 Layer 位（`RenderLayers.BG_2D` 与 `RenderLayers.FG_UI_2D`）严格隔离。
- 编辑器在后台未聚焦时，访问 `http://localhost:7456/asset-db/refresh` 可主动触发 Cocos 资源库刷新并生成 `.meta`、编译 `.effect` 与脚本。
