## 模块

一个模块一行：路径、它负责什么、别人怎么用它。

- `assets/scenes/Main.scene`：唯一场景，仅含 `Canvas`（1624 × 750）、`Camera` 和挂载在 `Canvas` 上的 `Boot`。
- `assets/scripts/Boot.ts`：场景唯一入口组件，初始化碰撞矩阵并搭建 `Machine`（等比缩放居中）、`TankRoot`（含物理步、水缸、双柱、圈层、调试工具）与最上层 `ShellView`。
- `assets/scripts/config/LayoutConfig.ts`：1624 × 750 整机各分区矩形常量、`rectCenter` 与 `calcMachineScale`（纯 TS，不依赖 `cc`）。
- `assets/scripts/config/TankSpace.ts`：缸坐标工具（原点在内屏左下角，提供 `0~100` 百分比、像素与机器坐标互转，纯 TS）。
- `assets/scripts/config/GameConst.ts`：全局调试开关 `DEBUG` 与圈/柱/缸壁/喷流锥角及扰动尺度常量与几何计算（纯 TS）。
- `assets/scripts/config/FeelConfig.ts`：手感参数配置（含柱位、海眼位与倾角、气囊单口气与回充秒数、衰减秒数及临时圈阻尼/水速，T010 补齐并换算，纯 TS）。
- `assets/scripts/config/PhysicsGroups.ts`：碰撞分组位掩码（`RING_END`/`RING_BAR`/`PILLAR`/`WALL`/`MECH`）与对称碰撞矩阵写入 `applyCollisionMatrix`（纯 TS）。
- `assets/scripts/config/Palette.ts`：灰盒配色表（机身、内屏底色、水缸角、双柱、七种圈、占位框与标注文字颜色）。
- `assets/scripts/core/rings/RingKinds.ts`：圈种（普通 4 色、小金环、铁圈、木圈）尺寸/下沉/跟随倍率及 `sameKind` 配对规则（纯 TS）。
- `assets/scripts/core/flow/CurlNoise.ts`：用 `SeededRandom` 初始化排列表的二维旋度噪声，采样纯函数不消耗随机数（纯 TS）。
- `assets/scripts/core/flow/FlowField.ts`：缸坐标水流速度场（主喷流、全缸环流、少量扰动及 `addTerm`/`removeTerm` 扩展项，纯 TS）。
- `assets/scripts/core/flow/WaterFollow.ts`：单端点水流跟随加速度纯函数 `calcEndpointFollowAccel`（纯 TS）。
- `assets/scripts/core/input/Bladder.ts`：软胶气囊模型 `Bladder` 与键帽下陷姿态计算 `calcSoftCapPose`（纯 TS）。
- `assets/scripts/game/PhysicsStepper.ts`：包住 `physicsWorld.step`，提供步前/步后回调、`running` 暂停开关与累计物理时间 `elapsed`。
- `assets/scripts/game/TankGeometry.ts`：计算四面缸壁与左右底角圆弧折线及凸条带多边形的纯几何函数（纯 TS）。
- `assets/scripts/game/Tank.ts`：挂载于 `TankRoot` 下，生成缸壁与底角静态碰撞体并用单个 `Graphics` 绘出内屏深水底色、水缸边界与左右海眼标记。
- `assets/scripts/game/Pillar.ts`：创建左右对称悬空柱与底托（静刚体 + 碰撞体），两柱共用父容器上的一个 `Graphics` 绘制。
- `assets/scripts/game/Ring.ts`：圈物理体组件（动态刚体、挂载前开启 `bullet`、双端点 `RING_END` + 横条 `RING_BAR`）。
- `assets/scripts/game/RingLayer.ts`：圈管理与共享绘制层，用单个共享 `Graphics` 按倾角绘扁椭圆并在每个物理步前施净下沉力。
- `assets/scripts/game/WaterForce.ts`：挂载于 `TankRoot`，每个物理步前推进气囊与 `FlowField` 并对未锁定圈的双端点分别施水流跟随力。
- `assets/scripts/render/BubblePool.ts`：水流气泡零 GC 对象池与流速视觉映射纯逻辑，限定上限常量并在缸壁与底角圆弧内采样 `FlowField` 漂移（纯 TS）。
- `assets/scripts/render/Bubbles.ts`：挂载于 `TankRoot` 下 `Tank` 之后、`Pillar` 之前，用单个共享 `Graphics` 按透明度合批绘出环境与海眼气泡。
- `assets/scripts/debug/PhysicsDebugDraw.ts`：受 `GameConst.DEBUG` 控制，按 `P` 键切换 `PhysicsSystem2D` 碰撞框显示。
- `assets/scripts/debug/RingDebugSpawner.ts`：受 `GameConst.DEBUG` 控制，点击内屏放圈、数字键 `1–7` 切换圈种、`R` 清空。
- `assets/scripts/ui/ShellView.ts`：灰盒掌机外壳组件，用单个共享 `Graphics` 画出挖空内屏的外壳和各分区占位框并标注文字。
- `assets/scripts/ui/JetButton.ts`：左右软胶喷射键（触屏多点独立与键盘 `F`/`J`、随气囊余量下陷回弹），左右键共用一个 `Graphics`。
- `assets/scripts/core/util/SeededRandom.ts`：mulberry32 种子随机数生成器，提供 `next()`、`range(min, max)`、`int(max)`，玩法逻辑统一用它代替 `Math.random()`。
- `tests/core/purity.test.ts`：`core/` 纯净度检查，扫描 `assets/scripts/core/` 禁止引入 `cc`。
- `tests/core/util/SeededRandom.test.ts`：`SeededRandom` 单元测试（同种子同序列、不同种子不同序列、范围校验）。
- `tests/core/rings/RingKinds.test.ts`：`RingKinds` 倍率、配对规则 `sameKind` 与调试预设单元测试。
- `tests/core/flow/FlowField.test.ts`：`FlowField` 锥形喷流、顺逆时针环流衰减、种子扰动复现与加项接口单元测试。
- `tests/core/flow/WaterFollow.test.ts`：`WaterFollow` 端点跟随加速度及双端点水流积分（沉底、轻点、按满、半偏翻转、环流）单元测试。
- `tests/core/input/Bladder.test.ts`：`Bladder` 轻点/按满出水量比例、超时归零、松手回满与极快连点衰减单元测试。

## 约定与坑

下面几条来自旧项目 `C:\Users\l\cursor\xiaoyouxi-001\docs\进度.md`，同一台电脑、同一个引擎版本上实际遇到过：

- Cocos 没有"物理步之前"的回调。要在每步前施力，就包住 `PhysicsSystem2D.instance.physicsWorld.step`（旧项目 `assets/scripts/physics/WaterField.ts` 的 `onEnable`）。在 `update` 里施力会忽强忽弱，也不可复现。
- 暂停时跳过物理步，不要用 `PhysicsSystem2D.instance.enable = false`：关掉后节点的移动不再同步给刚体。
- 水流的"强度"按加速度理解，施力时乘以质量，再换算成 Box2D 的米制单位（`PHYSICS_2D_PTM_RATIO` = 32）。直接把像素量级的数当成力会把圈打飞。
- Box2D 里下沉的最终速度约等于 重力 ÷ `linearDamping`，调"沉底要几秒"时两个量要一起看。
- 每个 `Graphics` 组件约占 2MB 显存，同类图形共用一个。
- `resources.load` 会缓存 JSON：改了关卡文件要刷新预览页面才生效。
- 浏览器标签页在后台时帧率会被压到很低，物理时间跟着变慢。测手感和帧率时窗口要在前台。
- 用 Cursor 内置浏览器测试时，顶部如果出现蓝色的 "Click to select…" 提示条，所有点击都会被它拦住，先点左边的 × 关掉。
- 键盘调试键要先在游戏画面里点一下，画布拿到焦点才有反应。
- 命令行构建微信包时要先关掉编辑器里的这个项目，退出码 36 表示成功（命令见旧项目进度文档第 12 项）。
- 旧项目的 `settings/v2/packages/engine.json` 里 `3d` 模块是关着的（2D 模板的默认值）。本项目的圈和柱子要用 3D 网格，必须打开。
- Cocos 3.8.8 自带的 `cc.d.ts` / `jsb.d.ts` 含少量未导出的 WebGPU 与内部类型，命令行跑 `tsc --noEmit` 必须在 `tsconfig.json` 开启 `"skipLibCheck": true`。
- 2D 空模板 `empty-2d` 的 `engine.json` 默认把 `video`、`spine`、`dragon-bones` 开着，初始化时需主动关掉。
- Cocos 3.8.8 `b2PhysicsWorld` 在把 `debugDrawFlags` 设为 `0` 时会把 `_debugGraphics.node.parent` 置为 `null`，若不挂回 `Canvas` 直接再次开启会空指针报错（已在 `PhysicsDebugDraw.ts` 中规避）。
- Cocos 3.8.8 规定**每个 `.ts` 脚本最多只能有一个 `Component` 子类**（`@ccclass`）。把两个 `Component` 写在同一文件会报 `Each script can have at most one Component` 并抛异常中断引用链，导致 `Boot` 在 `Canvas` 上报 `Missing class`。
- `RigidBody2D.bullet` 只是普通字段，仅在刚体首次创建（节点激活）时读取，必须在 `parent.addChild(node)` 之前设为 `true`；对已激活节点动态 `addComponent(Collider2D)` 后修改 `size`/`offset`/`points`，必须显式调用 `collider.apply()` 才会同步给 Box2D 夹具。
- `RigidBody2D.getWorldPoint(localPt, out)` 不会自动乘 `node.worldScale`，而 Box2D 碰撞夹具在创建时会把 `offset` 乘上 `worldScale`；窄屏缩放 `Machine` 时，取端点世界坐标必须手动把本地偏移乘上 `worldScale`，多子步物理期间取缸坐标也应从 `body` 换算而非读滞后的 `node.position`。
- 编辑器在后台未聚焦时，访问 `http://localhost:7456/asset-db/refresh` 可主动触发 Cocos 资源库刷新并生成 `.meta`、重编脚本。
