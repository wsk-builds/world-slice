### T055 道具「牵引」

依赖：T054、T048、T049　GDD：§7.1（含表格下面那一段）

**做什么**

选出离柱子最近的三个"自由且合法"的圈，让它们直接飞到有空位的柱子上，照常锁定、消除、充能。合法的意思：分类关里颜色对得上；解救关里不选被困的圈。水里没有可选的圈时按钮变暗，点了不消耗。选圈规则写在 `core/rules/PullRule.ts` 并写单元测试。

**你来验**：水里有 5 个圈时点牵引：最近的 3 个飞上柱子。圈全部被冰冻住时，按钮是暗的。

### T059 四个广告点与广告规矩

依赖：T058、T054　GDD：§7.2、§7.4

**做什么**

1. `core/meta/AdRules.ts`（纯逻辑，写单元测试）：没看完不给；拉不到时直接发放，每天最多 3 次；开局助力只在这一关失败过一次之后出现，每局一次；奖励翻倍每次里程碑通关一次。
2. 四个广告点：
   - 失败续时：时间到时弹出；看完加 20 秒，圈保持原位；只剩一两个圈时，弹窗上写"只差 N 个圈"。
   - 开局助力：重试界面上出现；本局总时间加 30%。
   - 局内用道具：库存为 0 时点道具键；看完立即用一次。
   - 奖励翻倍：里程碑关通关后；道具奖励 1 个变 3 个（奖励本身 T060 做，这里先留接口）。
3. 进关时预加载广告。广告期间倒计时和水缸都停；回来后先停 1–2 秒再恢复。
4. 每个广告点一个独立的广告位编号，放在 `config/AdUnits.ts`，现在先用占位字符串。

**你来验**：故意输一局，弹出"续时"；看完假广告后加 20 秒继续，圈没动过。再输一次去重试，出现"开局助力"。库存为 0 时点道具键，看完假广告后道具生效。假广告选"中途关闭"，不给奖励。
