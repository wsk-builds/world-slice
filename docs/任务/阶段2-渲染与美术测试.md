### T027 🔶 三相机夹心架构

依赖：T026　GDD：§3.1

**做什么**

1. `render/Stage3DRig.ts`：用代码创建三台相机和各自的独立 `RenderLayers`（避免多台 2D 相机重复绘制同一层）：
   - 相机 1（`BG_2D`）：内屏里的 2D 背景、海眼和水中角色、气泡。
   - 相机 2（`RING_PILLAR_3D`）：微俯视透视 3D，只拍圈和柱子，`z=0` 平面和 2D 缸坐标 1:1 对齐。
   - 相机 3（`FG_UI_2D` / `BOSS_BREAKOUT_2D`）：2D 前景特效、挖空外壳、按键、调参面板，以及给首领战预留的"破框层"（画在外壳之上）。
2. 把已有的节点分到对应的层：背景、气泡 → 相机 1；3D 圈柱 → 相机 2；外壳、倒计时、调参面板、碰撞调试线 → 相机 3。
3. `Machine` 缩放、窗口大小变化时，三台相机保持对齐。

**你来验**：画面和之前一样；按 P 的碰撞框、气泡、3D 圈柱、外壳的前后层次正常；拉伸浏览器窗口不错位。

### T028 3D 圈与柱子（占位网格）

依赖：T027　GDD：§3.1、§3.2

**做什么**

1. `render/MeshFactory3D.ts` & `game/Ring.ts`：用 `primitives.torus` + `MeshUtils.createMesh` 生成标准正圆环 3D 网格；每个圈一个 3D 节点，每帧从真 3D 刚体 `TorusBody3D` 直接同步三维位置 `(x, y, z)` 与旋转四元数 `quat`。
2. `render/MeshFactory3D.ts` & `game/Pillar.ts`：程序生成复刻参考视频的三段式「上尖下粗圆锥杆（带圆润球顶）+ 十字四翼卡托 + 下端悬空收尖尾椎」3D 网格。
3. 配备零灯光球面高光着色器 `assets/resources/effects/matcap.effect`，颜色按圈种设置；打开硬件深度缓冲：圈套在柱上时，前半圈挡住柱子，后半圈被柱子挡住。
4. 按 P 键在 `PhysicsDebugDraw` 开关 3D 圆环与锥形十字柱胶囊骨架的 2D 投影轮廓显示。

**你来验**：圈看起来是立体的正圆环，在水流里三轴真翻转；套在柱上时柱子从环中间穿过，前后遮挡是对的；小金环更小。

**完成记录 T028**：
- 已按用户参考视频 3D 重设计要求提前完成并实测通过（2026-11-13）：`render/MeshFactory3D.ts` 生成标准正圆环 `Torus` 网格与三段式锥形十字柱 3D 网格，配合 `assets/resources/effects/matcap.effect` 零灯光球面高光着色器与 `TorusWorld3D` 真 3D 刚体同步位置和四元数，硬件深度缓冲自动处理圈柱穿插遮挡。
- 审核：高级模型直接完成（2026-11-13）。

### T029 🔶 MatCap 材质

依赖：T028　GDD：§3.1、§9.2「圈和柱子」、附录「圈」「柱子」

**做什么**

1. 复用并完善已建好的 `assets/resources/effects/matcap.effect`（已含 `USE_MATCAP_TEX` 宏与无光照球面采样，场景零灯光、零阴影）。
2. `tools/gen-matcap.mjs`：生成 128 × 128 的占位 MatCap 球图 6 张（琉璃、亮金、黑铁、木纹、虹彩、玉柱），输出到 `assets/resources/art/matcap/`，以后用同名的正式图替换。
3. 在 `render/MeshFactory3D.ts` 中加载球图并开启 `USE_MATCAP_TEX` 赋给 `matcapTex`（注意新贴图/材质初始化后需赋新 `Material` 实例刷新 `MeshRenderer` PSO）。普通圈四种颜色由代码改主色，共用同一张琉璃球图。

**你来验**：圈上有各自材质质感的球面高光，翻转时高光跟着流动；红绿蓝橙是同一种琉璃质感、不同颜色；金、铁、木、玉柱一眼能分清。

### T031 🔶 2D Shader：顶点摆动与噪声溶解

依赖：T030　GDD：§9.2「轻量 2D Shader 减负」第 1、3 条

**做什么**

1. 顶点正弦摆动：给 2D 精灵用的 effect 和一个小组件，可以设幅度、频率、相位，以及"根部不动、越到尖端摆得越大"的方向。单张整图就能摆，不切关节。
2. 噪声溶解：给 2D 精灵用的 effect 和小组件，可以设溶解进度（0–1）和边缘发光颜色。`tools/gen-noise.mjs` 生成 256 × 256 的噪声图。
3. 两个都要能和 Cocos 的 2D 合批正常共存，不破坏别的精灵的显示。

**你来验**：T035 的测试台里看。这一项做完时，AI 会放两个临时的色块演示：一个像水草一样摆，一个慢慢溶解消失。

### T033 🔶 程序调色底板与水体微折射

依赖：T030　GDD：§9.2「背景」、Shader 第 2 条

**做什么**

1. 水体底板：纯代码的渐变（上亮下暗），加五幕色调表：子夜青蓝、寅时深蓝、卯时冷青、辰时暗紫、破晓澄澈蔚蓝。`setAct(1–5, 过渡秒数)` 平滑切换。
2. 微折射：叠在内屏背景层上的轻微画面扰动，强度可调，默认很弱。只影响背景，不影响圈和气泡。
3. 景片槽位：远、中、近三层，从 `ArtTable` 取图，没有图就空着。
4. 调参面板里加一个切换 1–5 幕的调试按钮。

**你来验**：调参面板里切 1–5 幕，水色平滑过渡，五种一眼能分开；背景有极轻微的荡漾，不晃眼；圈和气泡依然清楚。
